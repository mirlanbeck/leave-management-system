### 1.2. Имя проекта compose

```
$ docker compose ls -a
leave-management   running(4)   C:\...\leave-management-system\docker-compose.yml
$ docker volume inspect leave-management_pgdata → project:leave-management, CreatedAt 2026-10-23T09:47:35Z
$ docker compose config               → default: leave-management [ 'leave-management_pgdata' ]
$ COMPOSE_PROJECT_NAME=lms-fresh-s9k docker compose config → env: lms-fresh-s9k [ 'lms-fresh-s9k_pgdata' ]
```

Если клон из другой папки поднять обычной командой `docker compose up`, он получит тот же проект `leave-management`. Последствия:
- compose пересоздаст **ваши** контейнеры из образов клона и перезапишет теги `leave-management-api` и `leave-management-web`;
- клон подключит **ваш** том `leave-management_pgdata` с данными, так что проверка будет не «чистой»;
- `seed:demo` и `down -v` из клона ударят по вашему стеку.

`COMPOSE_PROJECT_NAME` перекрывает `name:` (вывод выше; тома `leave-audit-2_pgdata` и `leave-audit-3_pgdata` остались от аудитов именно так). Порты в compose зафиксированы, поэтому параллельно с вашим стеком второй стек не поднимется ни под каким именем: «port is already allocated».
