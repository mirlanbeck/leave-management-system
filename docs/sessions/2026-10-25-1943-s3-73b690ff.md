## Упущения в плане, которые исправляю в нём

1. **Тестовые файлы в сборке web.** `build` в web это `tsc --noEmit && vite build`, а `tsconfig` включает всю папку `src`. Файлы `*.spec.ts` попадут в проверку типов при сборке Docker-образа. ```

- **Время** — поле времени, по умолчанию `09:00` (RULES §9-3), а не текущее время часов.
- **Установить** отправляет `PUT /clock {date, time}`. Сервер сам переводит это в момент UTC. Из ответа обновляется значение слева, остальные вкладки подхватят его после перезагрузки.
