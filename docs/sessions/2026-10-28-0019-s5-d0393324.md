- **Changelog с 10.0.16 по 10.1.4** (читал из tarball). Есть один пункт, который касается наших таймаутов. Остальное наш код не затрагивает:
  - **10.1.0 `smtp-connection: count the wait for the greeting against connectionTimeout`.** Теперь ожидание приветствия входит в `connectionTimeout`. Худшее время отправки может только уменьшиться, так что `SMTP_SEND_MAX_MS = 5000 + 5000 + 10000` остаётся верхней оценкой, просто с запасом. `PASS_TIMEOUT_MS` остаётся корректным. Правки кода не нужны. Комментарий «соединение, приветствие, обмен» становится чуть неточным, но я его не трогаю (код api не меняем).
  - **10.1.0, ещё два пункта:** «421 завершает сессию» и «Nagle off» относятся к поведению SMTP. С Mailpit на них не наткнёмся. «Не читать env при импорте»: мы прокси через env не используем.
  - **10.1.1–10.1.4:** fetch/OAuth (не используем), ограничения нагрузки, addressparser (это и есть исправления).
