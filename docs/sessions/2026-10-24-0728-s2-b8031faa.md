PowerShell блокирует запуск `npm.ps1` политикой выполнения скриптов. Самый простой обход — вызвать `npm.cmd`, а не `npm.ps1`. Политику при этом менять не нужно:

```
npm.cmd ci
```

Если хотите, чтобы работало просто `npm`, есть два варианта:

- **Только для текущего окна PowerShell** (ничего не меняется навсегда):
  ```
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  npm ci
  ```
- **Для вашего пользователя навсегда:**
  ```
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
  Это системная настройка, поэтому решайте сами. Для аудита хватит первого или `npm.cmd`.

В Git Bash проблемы нет: там `npm ci` запускается как обычно.

После установки проверьте, что нужное установилось:
```
npm.cmd ls --depth=0
```
Затем перед запуском слепой сессии запустите один тест, чтобы убедиться, что окружение рабочее. Доменные тесты не требуют Postgres, поэтому лучше начать с них:
