## Агент · 19:34

`git branch -d feature/s2-audit-before-hire` удаляет **локальную** ветку с этим именем.

- **Что удаляется:** только указатель на последний коммит ветки в вашем репозитории. Сами коммиты остаются в истории `main` (PR смёржен), файлы на диске не трогаются.
- **Безопасный флаг `-d`:** git откажется удалять, если в ветке есть коммиты, которых нет в `main` или в её upstream. Тогда он напишет «not fully merged», и ничего не потеряется. Принудительное удаление — `-D`, его не используйте.
- **Что не удаляется:** ветка на GitHub (`origin/feature/s2-audit-before-hire`). Обычно её удаляют кнопкой «Delete branch» после мержа PR. Из консоли: `git push origin --delete feature/s2-audit-before-hire`.
- **Условие:** нельзя удалить ветку, на которой вы сейчас стоите. Поэтому сначала `git switch main`.

Команда необязательна: она нужна только для порядка, чтобы старая ветка не висела в `git branch`.
