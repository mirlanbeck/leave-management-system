# Аудит 3 — проверяемые утверждения (составлено ДО чтения кода)

Источники: `TMP-GENERAL-REQ.pdf` (PDF) и `docs/RULES.md` (версия от 2026-10-29).
ID: `§N-k` — раздел N RULES, k — номер пункта верхнего уровня в разделе (маркер «-» без отступа, считая сверху; таблица считается пунктом вместе с предшествующим маркером «Примеры»). Вложенные пункты различаются короткой цитатой. Нумерация сверена с внутренними ссылками RULES (§4-1, §5-5, §5-6, §8-2, §10-2) — совпадает.
PDF: `PDF-R-k` — «Требования» п. k; `PDF-E-k` — «Что мы ожидаем от вас» п. k; `PDF-I-k` — «Должен включать» маркер k; `PDF-B-k` — «Ожидаемое поведение» маркер k (сценарии задания).
`C-nnn` — сквозной номер для сверки полноты таблицы раздела 2 отчёта.
