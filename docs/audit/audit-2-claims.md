# Аудит 2 (S6) — проверяемые утверждения

Составлено ДО чтения кода (apps/, e2e/, scripts/) только по docs/RULES.md (версия 2026-10-28) и TMP-GENERAL-REQ.pdf.
Нумерация §N-k: k — порядковый номер пункта верхнего уровня в разделе RULES; вложенные пункты различаются короткой цитатой.

## A. Утверждения в области фокуса

### §4 Согласование
| ID | Источник | Утверждение |
|---|---|---|
| C4.1 | §4-1 | Согласует (одобряет/отклоняет) **только непосредственный** руководитель заявителя; руководитель руководителя (не прямой) — не может. |
| C4.2 | §4-1 | Комментарий при согласовании/отклонении необязателен (решение без комментария проходит). |
| C4.3 | §4-1 | Заявки руководителя согласует его руководитель; HR подчиняется заместителю; заместитель — директору (заявку HR согласует заместитель, не HR сам). |
| C4.4 | §4-2 | Заявки директора одобряет/отклоняет **HR** («допуск HR»); итог тот же — «Одобрена», дни списываются. |
| C4.5 | §4-2 | Это единственное исключение: HR не может согласовать/отклонить ничью заявку, кроме директорской (в т.ч. заявки своих коллег, прямых подчинённых других руководителей). |
| C4.6 | §4-3 | При согласовании остаток проверяется повторно по формуле «Доступно на дату начала» (§3-10). |
| C4.7 | §4-3 | Если дней не хватает — согласовать нельзя, заявка остаётся «На согласовании», руководитель видит причину «осталось X дней, в заявке Y». |
| C4.8 | §4-3 | Автоматического отклонения нет (после неудачного согласования статус не меняется). |
| C4.9 | §4-4 | Дни списываются сразу при окончательном согласовании, весь отпуск целиком (одна запись списания = все рабочие дни), включая отпуск следующего года. |
| C4.10 | §4-4 | Январская заявка, одобренная в декабре, учитывается до обрезки 1 января. |
| C4.11 | §4-5 | Заявка «На согласовании» после даты начала остаётся в этом статусе (никаких авто-действий), её можно согласовать задним числом с обычной проверкой остатка. |
| C4.12 | §4-6 | При согласовании — предупреждение о пересечении с **одобренными** отпусками прямых подчинённых или самого руководителя; не блокирует; «На согласовании» не учитываются. |
| C4.13 | §4-7 | Экран «Заявки на согласование»: только «На согласовании» и только от прямых подчинённых (включая переносы). |

### §5 Перенос и отмена
| ID | Источник | Утверждение |
|---|---|---|
| C5.1 | §5-1 | Перенос подаётся только если сегодня < даты начала исходного отпуска (по Clock/COMPANY_TZ). |
| C5.2 | §5-2 | Перенос подаётся только из **одобренного** отпуска (не из «На согласовании», «Отклонена», «Отменена», «Заменена переносом»). |
| C5.3 | §5-2 | Перенос — новая заявка, подчиняется §3 (год, ≥1 рабочий день, пересечения, backstopper, ...). |
| C5.4 | §5-2 | Перенос согласует только руководитель (директорский — HR). |
| C5.5 | §5-2 «Старый отпуск остаётся» | Пока перенос ждёт — старый «Одобрена» с пометкой; у старого недоступны «Отменить» и «Перенести» (второй параллельный перенос невозможен). |
| C5.6 | §5-2 «Число рабочих дней» | Число рабочих дней переноса = числу рабочих дней старого, иначе отказ с причиной. |
| C5.7 | §5-2 «Остаток не проверяется» | Остаток при подаче и при согласовании переноса не проверяется. |
| C5.8 | §5-2 «баланс не меняется» | При утверждении переноса нет новых списаний и возвратов; списание остаётся за старой заявкой. |
| C5.9 | §5-2 «Backstopper и даты» | Backstopper переноса обязателен; дата начала переноса ≥ сегодня; перенос в прошлое запрещён. |
| C5.10 | §5-2 «пересечений» | При проверке пересечений переносимый отпуск не участвует, остальные заявки сотрудника — участвуют. |
| C5.11 | §5-2 «нельзя утвердить» | Перенос нельзя утвердить, если старый отпуск уже начался (сегодня ≥ начала старого); можно только отклонить. |
| C5.12 | §5-3 | Отмена переноса (ожидающего) — только перенос «Отменена» + пометка «Старый отпуск остаётся»; старый — «Одобрена», пометка снимается. |
| C5.13 | §5-3 | Старый отпуск нельзя отменить (и HR не может отозвать) пока перенос ждёт решения. |
| C5.14 | §5-4 | Отмена до начала (одобренной или «На согласовании») — сотрудником без одобрения; дни (если списаны) возвращаются полностью. |
| C5.15 | §5-4 | До начала отпуск отменяет **только сотрудник** (не руководитель, не HR — кроме своего). |
| C5.16 | §5-5 | Отзыв — только HR, только при начало ≤ сегодня ≤ конец; из завершённого отзыва нет; из не начавшегося — нет. |
| C5.17 | §5-5 | HR отзывает свой собственный отпуск той же кнопкой. |
| C5.18 | §5-6 | Возврат при отзыве = рабочие дни с даты выхода по конец включительно (пример 19–30.10, выход 27 → 4). |
| C5.19 | §5-7/§5-9 | Сотрудник не может отменить начавшийся (сегодня ≥ начала) отпуск. |
| C5.20 | §5-8 | Прямого изменения дат у HR нет. |
| C5.21 | §5-10 | Заявку «На согласовании» после даты начала не отменяет никто (ни сотрудник, ни HR). |
| C5.22 | §5-10 | HR до начала не отменяет чужие отпуска и заявки. |
| C5.23 | §5-11 | Дата выхода при отзыве ∈ [начало; конец]; после окончания — отказ с пояснением; до начала — отказ; прошлое/будущее относительно сегодня допустимо; выход = начало → возврат всех дней. |
| C5.24 | §5-12 | Перенос хранит ссылку на исходную заявку; цепочка A→B→C; утверждение переводит предыдущее звено в «Заменена переносом». |
| C5.25 | §5-12 | Прежние звенья не оживают при отмене/отзыве действующего звена. |

### §6 (в части журнала, затрагиваемой фокусом)
| ID | Источник | Утверждение |
|---|---|---|
| C6.1 | §6-6 | Баланс вычисляется по журналу; отдельно не хранится. |
| C6.2 | §6-6 | Списание создаётся только при окончательном согласовании и остаётся за заявкой; у заявки-переноса собственного списания нет. |
| C6.3 | §6-6 | Возврат создаётся только отменой или отзывом и привязан к заявке со списанием. |
| C6.4 | §6-6 | approvedAt и дата отмены фиксируются по Clock в момент действия и не пересчитываются. |
| C6.5 | §6-8 | Возврат всегда привязан к списанию корня цепочки переносов. |
| C6.6 | §6-8 | Сумма возвратов по одному списанию ≤ списанного (в т.ч. при параллельных запросах). |
| C6.7 | §6-8 | Повторная отмена того же отпуска второго возврата не создаёт («уже обработана»). |

### §8 Уведомления
| ID | Источник | Утверждение |
|---|---|---|
| C8.1 | §8-1 | Канал только письма; других уведомлений нет. |
| C8.2 | §8-2 | Новая заявка → ровно одно письмо непосредственному руководителю. |
| C8.3 | §8-2 | Решение (одобрена/отклонена) → ровно одно письмо сотруднику. |
| C8.4 | §8-2 | Перенос: письмо о новой заявке — согласующему, о решении — сотруднику. |
| C8.5 | §8-2 | Заявка директора (вкл. перенос): письмо о новой заявке → HR; решение → директору. |
| C8.6 | §8-2 | Заявку HR согласует заместитель; письмо о новой заявке HR → заместителю; решение → HR. |
| C8.7 | §8-3 | Напоминание за N (REMINDER_DAYS, по умолч. 3) рабочих дней до начала, в 09:00 COMPANY_TZ, сотруднику и руководителю, по одному. |
| C8.8 | §8-3 «Дата напоминания» | N-й рабочий день до даты начала (сама не считается), и для старта в выходной (сб 14.11 → ср 11.11; вт 10.11 → чт 05.11). |
| C8.9 | §8-3 «в момент отправки» | Напоминание уходит только если в момент отправки статус «Одобрена». |
| C8.10 | §8-3 «Перенос» | После утверждения переноса напоминание старого не уходит; новый получает одно напоминание по новым датам. |
| C8.11 | §8-3 «Письма при переносе» | Нет писем про старый отпуск; одно письмо о решении по переносу; «Заменена переносом» писем не вызывает. |
| C8.12 | §8-3 «Уникальность» | Одно письмо на сочетание «тип + id отпуска + получатель». |
| C8.13 | §8-3 «одобрен слишком поздно» | Дата напоминания ≤ сегодня < начала → напоминание сразу после согласования (в любое время суток), плановое не создаётся. |
| C8.14 | §8-4 | Если сегодня ≥ начала — напоминание не отправляется (письмо о решении уходит). |
| C8.15 | §8-5 | Получатели напоминания: сотрудник и его руководитель; у директора — только он сам. |
| C8.16 | §8-6 | HR не получает напоминаний (кроме своего отпуска); о своём отпуске HR — решение и напоминание; заместитель получает напоминание об отпуске HR. |
| C8.17 | §8-6/§8-7 | HR получает письма только о новой заявке директора (вкл. перенос) и о своих заявках; писем об отменах/переносах — нет. |
| C8.18 | §8-8 | Отмена (в т.ч. переноса) и отзыв писем не порождают. |
| C8.19 | §3-3 | Backstopper писем не получает. |

### §10 Конкурентность и календарь
| ID | Источник | Утверждение |
|---|---|---|
| C10.1 | §10-1 «уже обработана» | Повторное решение (одобрение, отклонение, отмена) по обработанной заявке → отказ «уже обработана». |
| C10.2 | §10-1 «атомарно» | Проверка пересечений и остатка + смена статуса атомарны: из двух одновременных запросов проходит один (approve‖approve, approve‖reject, cancel‖cancel, cancel‖approve, создание двух пересекающихся заявок, два одобрения заявок, суммарно превышающих остаток). |
| C10.3 | §10-1 «ровно одно» | Письмо о событии ровно одно, в т.ч. при двойном клике/повторе. |
| C10.4 | §10-2 | Календарь/экран HR обновляются без перезагрузки на: одобрение, отмену (сотрудник/HR/отзыв), утверждение переноса, смену даты выхода. |
| C10.5 | §10-2 | Обновление получают только те, кому отпуск виден по §7. |
| C10.6 | §7-2 / §3-11 | Календарь показывает только «Одобрена» (не «На согласовании», не «Заменена переносом», не «Отменена»). |

## B. Предварительный список расхождений RULES ↔ PDF

1. **Комментарий при решении.** PDF: «Согласование руководителем: подтвердить или отклонить с комментарием». RULES §4-1: «комментарий необязателен». (Возможно, PDF имеет в виду возможность — решать автору.)
2. **Календарь команды для сотрудника.** PDF: «Календарь отпусков команды», «Календарь команды обновляется у всех, кто его смотрит». RULES §7-2: календарь сотрудника — «только себя». Сотрудник не видит календарь своей команды.
3. **Единица «за заданное число дней».** PDF: «За заданное число дней до начала отпуска ... напоминание». RULES §8-3: N **рабочих** дней. Скорее уточнение, но формулировки разные.
4. **Пересечения «в команде».** PDF: «Если в команде уже есть согласованный отпуск». RULES §4-6: прямые подчинённые согласующего и он сам. Для заявки руководителя (согласует заместитель) «команда» по RULES = прямые подчинённые заместителя, а не команда заявителя.
5. **Отмена после начала.** PDF: «Отмена после начала возвращает только неиспользованные». RULES §5-7/§5-10: после начала сотрудник отменить не может; «На согласовании» после начала не отменяет никто; только HR-отзыв. Возврат неиспользованных реализован как отзыв HR — уточнение, но сужение круга.
6. **Перенос без проверки остатка.** PDF: «Заявка на больше дней, чем будет накоплено к началу отпуска, не проходит». RULES §5-2: для переноса остаток не проверяется (перенос на более ранние даты после сдвига даты выхода).

## C. Предварительный список неоднозначностей RULES

1. §5-1 «HR отменяет его с возвратом неиспользованных дней (указывает дату выхода)» и §10-2 «отпуск отменён (сотрудником, HR, отзыв)» — существует ли «отмена HR», отличная от «отзыва»? Если да — когда (после окончания?).
2. Повторный отзыв (§5-5): допустим ли второй отзыв с более ранней датой выхода? §10-1 перечисляет «одобрение, отклонение, отмена», отзыв не назван.
3. Статус и календарь после отзыва: заявка становится «Отменена»? Календарь показывает использованную часть или убирает отпуск целиком?
4. Дата выхода при отзыве в выходной (сб/вс) — §5-6 «день выхода считается рабочим».
5. Перенос, ожидающий решения, дата начала которого наступила: по §5-10 его не отменяет никто, а пока он ждёт — старый нельзя отменить/отозвать (§5-3). Если старый уже начался, перенос можно только отклонить — тупик зависит от руководителя.
6. Отмена переноса: кто, кроме сотрудника? Может ли HR отменить ожидающий перенос директора/свой?
7. §8-3 «одобрен слишком поздно» при согласовании переноса: «дата напоминания» нового периода — при утверждении переноса письмо-напоминание сразу?
8. §8-3 «Уникальность ... id отпуска»: при цепочке A→B каждому звену своё напоминание? При откате часов и повторном одобрении той же заявки невозможно (статус) — но что если часы откатить на день до напоминания после отправки?
9. §9-5 и §10-1: при откате часов назад отменённая (в будущем по Clock) заявка — можно ли снова отменять/отзывать? Сравнение «сегодня» против дат событий.
10. §4-1 «непосредственный руководитель» — руководитель, сам являющийся backstopper'ом или пересечение; не важно. Но: может ли руководитель согласовать свою собственную заявку? (RULES говорит, что согласует его руководитель — подразумевает «нет»).
11. §6-8 «Сумма возвратов по одному списанию не превышает списанного» — при отзыве после частичного? Возврат один на заявку или может быть несколько?
12. §8-2: письмо о решении при «допуске HR» — от чьего имени/как называется; несущественно.
